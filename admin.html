כניסת מנהל

הזינו את הסיסמה כדי לערוך את ההודעה הקופצת.

המערכת עדיין לא מחוברת למאגר נתונים אפשר לערוך ולראות תצוגה מקדימה, אבל השמירה לא תעבוד עד שיושלם החיבור ב־Vercel:
  1. Vercel → הפרויקט morcafe → לשונית Storage → Create Database → Upstash for Redis (מסלול חינמי) → לחבר לפרויקט.
  2. Settings → Environment Variables → להוסיף ADMIN_PASSWORD עם הסיסמה הרצויה.
  3. Deployments → Redeploy.
ההודעה כבויה המבקרים באתר לא רואים שום הודעה
